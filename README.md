# Clima Agora

> **Live demo:** [clima-agora-hcei1g4kz-williamfariascorrea-engs-projects.vercel.app](https://clima-agora-hcei1g4kz-williamfariascorrea-engs-projects.vercel.app)

A clean, real-time weather app built with **React, TypeScript, Vite and Tailwind CSS**. Search any city or use your location to get accurate conditions — with a 7-day forecast.

## ✨ Features

- **Live weather** — current temperature, conditions and details for any city
- **7-day forecast** — daily temperature range and conditions
- **City search** — find any city by name
- **Geolocation** — one click uses your current position
- **No API key needed** — powered by the free **Open-Meteo** API
- **Fully responsive** — mobile and desktop friendly
- **Dark theme** — polished Tailwind design

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Production build
npm run build

# Preview the build
npm run preview
```

## 🔌 API

This app uses the free [Open-Meteo API](https://open-meteo.com/) — no registration, no API key. Just fast, reliable weather data.
